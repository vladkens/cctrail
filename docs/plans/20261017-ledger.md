# Ledger

Keep the parsed history in cctrail's own database, so numbers survive when the logs are gone (Claude
Code deletes sessions older than 30 days by default), a new machine doesn't need the old logs, and a
run reads only what changed. First step: `cctrail export FILE`, a backup in the format the ledger
and `import` will read.

## Export

- `cctrail export FILE` reads the history as the reports do and writes it into a new SQLite file
  (rusqlite with its bundled SQLite), through a temporary file beside it.
- Contents: per history file (fx: a session directory) its path, size, mtime, parser version and
  swear dictionary, and what reading it alone gives: its one session (id, main, directories,
  remote), its events (time, model, six token counts, speed, effort, the harness's cost, the
  summed, background, sidechain and failed flags, Claude's dedup identity, the prompt's swear
  counts, `directed`, hash and model) and, as JSON, the links the work across files needs (Claude's
  agent calls, fallbacks and meta tool id; Codex's rollout meta, agent calls and token count
  signatures; pi's header and entry keys; fx's parent, agent activity and per-model totals). Never
  text. Tables `files`, `sessions`, `events`, `strings` (models, efforts) and `meta` (format
  version, cctrail version, export time); paths under the home directory as `~/…`.
- The boundary: each parser is split into `find` (the files, with size and mtime), `read` (one
  file alone) and `combine` (the work across files: profile copies, Claude's agents and fallbacks,
  Codex's copies per root and profile, fork replay and agents, pi's lineage, fx's agents and usage
  spread over local days). The file keeps `read`'s results, so a later `import` runs `combine` on
  them with the files then on disk and copies and forks count as in a full parse. Nothing that
  depends on the time zone (fx's spread) is stored.

## Later

- The ledger: the same tables in `$XDG_DATA_HOME/cctrail/ledger.db`, updated on each run (files
  unchanged by size and mtime under the same parser version come from it, the sessions of gone
  files stay), and `cctrail import FILE` merging an export into it. A first version with these and
  its safeguards (no deletion of a gone file's rows, a backup before a parser version bump, WAL,
  writes under the write lock) is on the local branch `feat/ledger-full`.
