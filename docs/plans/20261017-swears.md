# Swears per model

`cctrail swears` shows how often the user swears at each model: a light measure of which model
frustrates the most.

## Thoughts

- Count only the user's own prompts: no tool output, injected context, command wrappers, or
  prompts that a model wrote for a subagent. A prompt copied by a fork counts once.
- A prompt counts toward the model that answered last before it in the same session.
- Output: model (or project with `--by project`), prompts, prompts with swearing, share, top words,
  and JSON. Never print or store prompt text.
- Dictionaries in `src/swear/<lang>.txt`, English and Russian first: exact words, `stem*` prefixes
  for inflected languages, `!word` exceptions against false positives. More languages as pull
  requests; personal lists in `~/.config/cctrail/swear/`.
- Speed: matching is linear in text (a hash set and a prefix list); prompt text is read only for
  this command, so the default report doesn't slow down. Measure both.
