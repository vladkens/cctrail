# Clones by name and --all

The same repository checked out at several paths (an old disk, `~/Code/pub/<repo>` beside
`~/Code/<repo>`) showed as separate rows, and the only fix was a config entry per path. Fold clones
by their directory name instead, with as little machinery as possible, and let the person see every
row without the `other` collapse.

## Decisions

- After worktree folding, directories with the same last path component fold into the one with the
  latest activity; it labels the row and JSON `paths` lists the folded ones.
- Never folded: system temp directories (`/tmp`, `/private/tmp`, `/var/folders`, `$TMPDIR`), a
  directory that holds other session directories (`~/Code`), and directories Codex logged with
  different git remotes (`session_meta.git.repository_url`, the line `read_meta` already reads; a
  directory without a remote joins the latest compatible one).
- Config matching is unchanged: a root matching the logged directory but not the repository it
  folds into wins; otherwise the repository's project.
- `cctrail --all` (project view and `--by dir`) lists every row; the `other` hint points to it.
- Remote-based canonicals, log-tail reads and config aliases (dropped from #4) stay out.
