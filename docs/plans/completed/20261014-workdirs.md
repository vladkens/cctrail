# Workdir heuristics

One project shows up under many directories: agent worktrees (`<repo>/.claude/worktrees/<name>`,
`<repo>/.worktrees/<name>`, `<repo>/.ralphex/worktrees/<name>`, `<repo>-worktrees/<name>`). Fold
each session's working directory into the repository it belongs to before mapping it to a
project, so the config needs one root per repository and `--by dir` lists repositories, not
worktrees.

## Decisions

- Worktree patterns, by path alone (works for deleted directories):
  - `<repo>/.<tool>/worktrees/<name>[/…]` → `<repo>`, for any dot directory directly holding
    `worktrees`, except when `<repo>/.<tool>` is the Codex or Claude home itself
    (`~/.codex/worktrees/<id>/<repo>` names no repository path). Homes compare as paths
    (trailing separator; separators and case on Windows).
  - `<repo>/.worktrees/<name>[/…]` → `<repo>`.
  - `<parent>/<repo>-worktrees/<name>[/…]` → `<parent>/<repo>`.
- Clones at other paths are not folded: the config lists each clone's path. Folding them by the
  git remote Codex logs was built and dropped as not worth its complexity (a scan of every
  rollout's head and tail, a canonical directory per remote, inferred config aliases, and their
  edge cases).
- Config matching: a root matching the logged directory but not the repository it folds into is
  the worktree's own (`<repo>/.worktrees/<name>`, `<repo>-worktrees/<name>`) and wins; otherwise
  the repository's project, so a catch-all root above the repository doesn't take its worktrees.
- `--by dir` groups by the folded directory. JSON keeps `workdir` (folded) and adds `paths`, the
  logged directories folded into it, sorted. Reports by period don't fold.
- Numbers: total tokens, cost and sessions stay identical to `main`; total active time may differ
  by a second per group from rounding. Per-group numbers change by design.
- `make compare` no longer has a Python reference (the port is done): it compares the branch with
  a `main` build (`REF=<binary>`) and prints per-case totals and differences, failing only on
  totals. agents.md's Correctness section matches.

## Result

Agent worktrees fold into their repository by path alone; clones stay separate directories that
the config lists. An earlier version with remote-based clone folding kept totals identical to
`main` on the full history; this one only removes rules from it.
